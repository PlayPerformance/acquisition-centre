# Play Performance Acquisition Centre

Mobile-first site where buyers browse Play Performance stock at set prices, hit **Buy now** (first in wins), track delivery and message the team. Staff add cars, post tracking updates and reply to messages from the Admin tab.

- Hosting: GitHub Pages (this repo)
- Database, logins, photos: Supabase project `acquisition-centre` (Sydney)
- `setup.sql` / `schema.sql`: database structure and security rules
